# Fieldnote Pricing

InternCircle Project 03. A responsive pricing section for a fictional project planning product.

[Open the live pricing page](https://vishaldluffy.github.io/pricing/)

The Monthly and Yearly buttons update all displayed prices and billing labels from HTML data attributes. Yearly prices are approximately 20% lower than twelve monthly payments. The Pro plan appears first below 800 px. Hover movement respects the operating system's reduced-motion preference. Plan buttons open an informational demo dialog.

Serve this folder with Live Server for local development. No build step or external dependencies are required.
